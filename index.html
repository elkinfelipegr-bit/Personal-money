          Tus datos

          Registrar sin abrir la app

          Esta dirección abre la app con el texto ya escrito. Úsala en Atajos de iPhone o rutinas de Android:

          📱 iPhone: registrar solo cada aviso del banco
          1. Abre Atajos → Automatización → + → Mensaje.
          2. En «El mensaje contiene» escribe el nombre del banco (p. ej. Bancolombia) y elige Ejecutar inmediatamente.
          3. Acción: Abrir URL con la dirección de arriba cambiando el final por ?text= y el Mensaje (variable).
          4. Cada SMS del banco abrirá Mi Plata con el gasto listo para confirmar.
          🤖 Android: compartir el aviso a la app
          1. Instala Mi Plata en la pantalla de inicio (menú de Chrome → Instalar app).
          2. En el SMS o la notificación del banco, mantén presionado → Compartir → Mi Plata.
          3. Para hacerlo automático, apps como MacroDroid pueden abrir la dirección de arriba con ?text= y el texto de la notificación.
